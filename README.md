# Megan Mulcahy — portfolio site

## Files
- index.html — page markup
- styles.css — all styling
- main.js — "Read more" toggles on project descriptions
- assets/ — project images (PNG)

## Running it
Open index.html in a browser, or upload the whole folder to any static host.

## GitHub Pages
Copy these files to the root of MeganMulcahy.github.io and push. Fonts load from Google Fonts, so an internet connection is needed for the typefaces.

## Replacing an image
Drop a new file into assets/ using the same filename, or edit the <img src> in index.html.
